🔧 Dev Tools

Developer tools for the Empire project

Economy
⚡ Effects Overview All effect keys by building and category. Filter effects, inspect values and debug. via API ⚙ Game Settings All game balance in one place: Game Config, Era Effects, and Workshop upgrade costs. via API ✨ Artifacts Edit artifact definitions: name, type, passive effects. Save directly to artifacts.yaml. via API 👑 Rulers Configure rulers: name, type, skills Q/W/E (5 levels) and R (3 levels) with effect dicts. via API 🏆 Trophies View earned trophies per empire — integrated in Status page. via API 🎛️ Sigmoid Tuner Interactively calibrate price curves for citizens, tiles, waves and critters. Copy-ready values. Local ⏱ Effort Tuner Adjust build and research times per era. Time estimates with speed boosts. Save directly. via API 🐾 Critters Gallery of all critters by era with zoom + scale normalization. Inspector tab for frame-by-frame sprite preview. via API 📊 Unit Scatter All critters and towers as a scatter plot. X-axis: era, Y-axis: power index. Color-coded by class. via API ⚖️ Balance Overview Critters vs. towers per era: DPS, unlock effort, counter pairs and balance warnings. via API
Battle
🌊 AI Wave Composer Define attack waves per era, set triggers, configure travel and siege times. via API 🤖 AI Army Generator Auto-generate AI armies based on era, tower value, path length and buildings. Tune weights via sliders. via API ⚔ Send AI Army Manually send an AI army to an empire. Empire analysis with power index, tower costs and path length. via API 🤖 Bot Status Live strategy, 48 h history, breach triggers, savings goals, defense histogram and capabilities per bot. via API 📈 AI Battle Log Scatter plot of all AI attacks: tower gold vs. era. Green = defender wins, red = AI wins. via API ⚔ Sim Map Simulate battles on a map: place towers, spawn waves, observe combat resolution. via API 🧩 Maze Simulator Time-accelerated test of the bot maze build strategy — runs the real DefensePlanner against an in-memory map. via API 🗺 Map Overview Hex maps of all empires: power index, path length, tower stats. Rename and delete. via API
Helpers
💾 Backup Overview All hourly and daily backup slots with timestamps, consistency check, user and empire counts. via API 📊 Server Status Live overview: connections, all empires, life, culture, citizens and active attacks. via API 🗄️ Database Admin Manage user accounts: create, delete, reset password. via API 🌍 Global Map World-level map view of all empires and their positions. via API
